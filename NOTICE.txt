htop 3.5.3 for tOS
==================

Built from the release tarball (htop-3.5.3.tar.xz beside this package), unmodified, with a static ncurses 6.5 (MIT; source beside this package). It reads /proc, which tOS makes up. License: GPL-2.0 or later (LICENSE).
glibc: its programs are linked dynamically against the GNU C Library, which tOS's base system carries in /lib64 and /lib/x86_64-linux-gnu.
